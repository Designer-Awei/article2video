# article2video

一个 Claude skill：把一份文案初稿做成用代码渲染的动画视频（科普、商单、产品介绍等，支持 16:9 和 9:16）。

## 流程
1. 读稿 → 判断用途和画面比例 → 粗分镜 → 列出需要补充的素材
2. 出四种风格样帧供选择
3. 写细分镜，出每个镜头的静帧预览，同时跑自动质检
4. 全量渲染：按改动增量渲染，镜头间加转场合成，再压制交付版
5. 按时间点返修，只重渲改过的镜头

默认输出带字幕的默片：字幕 90px，距底边 40px，没有音轨，同时导出 SRT 和时间线，方便之后人工配音。

## 使用
把 `script-to-explainer-video/` 目录放进 Claude 的 skills 目录，或在 claude.ai 的 Skills 设置里上传。
